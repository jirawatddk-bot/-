# AI Facebook Isan Quote Team

Autonomous 24/7 AI Multi-Agent system for managing Facebook Isan Quote Page.

## Features
- 7 AI Agents working in synergy
- Automatic Facebook Graph API Photo Post publishing
- SQLite database & history storage
- Custom day-by-day weekly topic schedule
- Automated GitHub Actions Workflow running at 06:00, 12:00, 18:00 Thai Time

## Setup GitHub Secrets
Configure the following Repository Secrets in GitHub:
- `GEMINI_API_KEY`
- `FACEBOOK_PAGE_ID`
- `FACEBOOK_PAGE_ACCESS_TOKEN`
